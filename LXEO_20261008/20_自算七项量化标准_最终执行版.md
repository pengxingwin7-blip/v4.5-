# §3 自算补充（行为簇无此项）（统一常规交易时段成交指标：09:30 ≤ t < 16:00 ET）

## 【统一口径】（本节 7 项共用，单项不再重复声明）

- 时间窗：RTH = 09:30 ≤ t < 16:00 ET。成交样本、分位阈值、确认窗口、宇宙筛选全部裁 RTH
- 订单生命周期：可跨窗口追踪（盘前挂出可计入存活时长；C 事件越出 RTH 不影响 life 计算）。
  候选资格按指标分：3.3 挂单墙 = 生命周期与 RTH 有交集即入候选；3.5 谎骗 = 新增与撤单均在 RTH 内才入候选
- 成交数据源：MBO 的 T 事件（禁止用 tick 文件代替）；depth5 仅用于盘口快照与 F→A 回溯
- 日高/日低：RTH 内 T 成交价的 max/min；
- 收盘价：RTH 内最后一笔 T 成交价（自算指标口径；官方收盘价仅在 §2 快照使用）
- 方向：T 行 side 即主动方（B=主动买，A=主动卖，N=无方向）；T(B)≡F(A) 仅恒等式
- 分位命名：成交分位（T 单笔 size，含 N）与挂单分位（A 事件 size）是两个不同分位，引用时必须写明哪个

【补充说明：所有股票 tick 固定为 0.01；同一时间戳按 MBO sequence 排序；分位数统一使用 linear，保留原始小数后比较；达到阈值的边界按 ≥/≤ 计入。】

【补充说明：M 不单独统计，只用于更新订单状态；R 不参与七项统计。F 有实际 fill_size 即算被动成交，不要求存在对应 T；该订单全部 F.fill_size 为 0 才算纯撤单。】

## 3.1 委比关键时刻（权重 L1~L5 = 1.0/0.6/0.35/0.2/0.1）

盘口源：MBO 去闪单（同 order_id A→C<1s 剔除）后重建的五档簿（depth_clean），
禁止直接用 depth5 预计算列（含闪单噪声）。

① 30min bar 基准（时间加权，非整点瞬时快照）：
   bar 内每 100ms 采样一次盘口 → 先求平均加权Bid/平均加权Ask → 再算委比。
   （整点瞬时值可被开盘薄盘扭曲，禁止用单点快照充当 bar 基准）
② 事件快照（单点）：每笔 P99 大单严格取事件时间前 1s、触及 ORH/ORL/VAH/VAL/POC(首次成交（之后1毫秒的委比）在ORH/ORL/VAH/VAL/POC价位瞬间盘口的委比）
   也使用同一规则；取该时刻及之前最近一行重建盘口。无可用盘口时标记 UNAVAILABLE，
   不得使用事件之后的数据补齐。
顺/逆势：主动买单对应委比>0 为顺势；主动卖单对应委比<0 为顺势；N 单标"无方向"。

【说明：关键价位事件按“首次触价成交后 1ms”取委比；P99 大单事件仍按成交事件前 1s 取委比。RTH 内共输出 13 个 30min bar。】

## 3.2 ISO扫单（30秒窗口；价格移动≥0.6%；成交量达到成交P99）

- 成交P99门槛样本：RTH 全部 T 成交（含 side=B/A/N）
- 窗口：每笔 RTH T 成交作为窗口起点，向后观察 30 秒；窗口包含起点和 30 秒边界内的成交
- 买入条件：窗口最高成交价 ≥ 首笔成交价×1.006，且窗口内 T(side=B) 成交量 ≥ 成交P99
- 卖出条件：窗口最低成交价 ≤ 首笔成交价×0.994，且窗口内 T(side=A) 成交量 ≥ 成交P99
- side=N：计入成交P99样本和窗口总成交量披露，不计入 B/A 方向成交量条件
- 重叠窗口：同方向时间窗口重叠时合并为一个 ISO 事件，买卖两侧分别处理

【说明：重叠窗口合并后重新计算合并区间的首笔价、方向极值价和方向成交量，不累加重复窗口；仅边界相接不算重叠。】

## 3.5 谎骗确认（150s穿越，depth5自算）

条件：挂单size≥挂单P98 + fill_ratio<15%被撤 + 撤后150s内 RTH 成交价穿越挂单价
- fill_ratio = 该 order_id 全部 F.fill_size 之和 / 首次 A.size；T 不重复计入
- 宇宙：RTH 内新增且 RTH 内撤单的订单（避免确认窗越出 RTH 造成"不可判定"虚高）
- Bid单：150s内出现成交价 < 挂单价 → 确认谎骗
- Ask单：150s内出现成交价 > 挂单价 → 确认谎骗
- 窗口内有成交未穿越 → 托单嫌疑；窗口内无 RTH 成交 → 不可判定
- 除上述三条件外不得自加排除规则（如存活下限、撤单距市价门槛——如需使用须在输出中单独披露）

## 3.7 预谋单

① 宇宙：RTH 内 A 挂单，首次 A 显示量 ≥ 成交P98（P98 样本含 N）
        且该单有 ≥1 笔 F 成交（被动成交挂单）
② 方向：挂单侧即方向（Bid 挂单=Bid被动，被主动卖单打；Ask 挂单=Ask被动）
③ 预谋检测：t_add=首次 A 时刻 → P_market=t_add 前最后一笔 RTH T 成交价
   → dist=|P_market−P_order|（tick+百分比）→ T_travel=挂出后价格首次触及 P_order
④ 判定：dist≤2tick → 实时反应（无论等多久）
        dist%≥1% 且 T_travel>120s → 真实预谋
        其余（含未到达）→ 中间区
⑤ 聚合：按 order_id 去重；量 = 该单全部 RTH F 累计 fill_size
⑥ 预谋方向比 = Ask被动 fill : Bid被动 fill

【说明：dist% = |P_market−P_order| / P_order ×100%，分母固定为挂单价 P_order；T_travel 使用挂出后首次触价时间；方向比按合格订单的 Ask/Bid 被动 fill 汇总。】
